# nutritional-semantic-analysis
When you bridge the gap between product strategy and data analytics, you start seeing everyday problems as data challenges. This project explores a massive dataset of over 230,000 Food.com recipes to understand why healthy food often loses out to comfort food. By analyzing the semantic gap, I found that unhealthy recipes are three to five times more likely to use highly appetizing keywords. To see if we could solve this branding problem and nudge users toward healthier choices, I built machine learning models using NLP and Random Forest to test personalized recipe recommendations. Interestingly, the analysis revealed the limits of hyper-personalization on crowdsourced platforms, showing that a simpler, statistically sound approach like Bayesian Average sorting is actually more effective at driving positive user behavior.
